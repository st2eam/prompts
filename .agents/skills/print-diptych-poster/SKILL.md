# 主题双联版画海报

将用户提供的参考图转化为一张可打印的竖版 3:4 海报。画面是严格上下双联：上半部分完整呈现参考图，下半部分把同一主题重新组织为极简纸感拓印拼贴。它是一次主题再创作，不是滤镜、描边、临摹、局部放大或把照片简单复制到海报上。

## 核心视觉指令

以下要求是本技能的默认视觉基线，除非用户明确修改，否则完整执行：

请生成一张竖版 3:4、可打印海报的上下双联画面，画面严格平均分为上下 1:1 两部分。上半部分呈现参考的图片；下半部分根据参考图片转化转化为极简纸感拓印拼贴封面：提取上方主题最具识别度的主体轮廓、姿态、空间关系、叙事关系和关键记忆点，删减复杂细节，不要写实复刻，也不要机械描边。使用粗糙米白底纸，叠加 3 到 4 种从上方画面提炼出的专色，保留轻微错位套印、颗粒网点、纸张纤维、手工裁切边缘和少量印刷漏墨感。线条负责提示结构，色块负责建立主体，主体小而集中，四周保留大量留白。可加入极少量清晰英文小字，如主题名，排版疏朗克制。下半部分高度提炼但一眼能识别原始主题。整体需要像独立出版物封面、艺术展览海报或收藏级视觉研究员，构图安静、现代、克制、高级。

负面提示：商业旅游海报、电商模板、3D 渲染、过度写实插画、纯线稿、色彩超过 4 种、画面过满、廉价卡通、复杂透视、光滑数字插画、文字乱码、伪文字、水印、比例不均

## 工作流程

1. **先检查参考图**：识别主题主体、主体轮廓与姿态、前后关系、主要空间轴线、叙事动作、最容易辨认的两个到四个记忆点，以及应当舍弃的复杂细节。
2. **建立上下分镜**：先画一条位于画布正中、不可偏移的水平分割线。上下区域各占 50% 高度，不允许标题、主体、纹理、边框或留白把分割线视觉推离中心。
3. **保留上半部分真实性**：上半部分以参考图为主，保持主体、空间关系、色彩氛围和关键细节可辨认。不得将上半部分也处理成插画，不得因为排版而裁掉主题主体；只有在用户明确要求时才改动摄影区域。
4. **提炼下半部分语义**：只保留能让人一眼回认上方主题的结构。允许改变比例、视角、形状、排列和色块关系；禁止逐像素描边、完整复制原构图或保留所有现实细节。
5. **选择一套版画语法**：以粗版画块面、浮世绘木刻方向线、现代海报色块、纸张拓印、手工裁纸拼贴中的一至两种为主。线条提示结构，色块建立主体，纹理只证明材料，不得成为装饰噪声。
6. **控制颜色**：下半部分最多使用 3–4 种从上半部分提炼的专色，加粗糙米白纸底。颜色应服务于主体辨识、视觉层级和主题叙事；不要加入与参考图无关的潮流色、霓虹色或渐变色。
7. **控制密度**：下半部分主体小而集中，周围保留大面积干净纸面。把树叶、建筑细节、人物五官、纹理和背景杂物合并为少量大形，不用增加细节来填满空间。
8. **加入有限印刷痕迹**：只使用轻微错位套印、颗粒网点、纸张纤维、手工裁切边缘和少量漏墨。所有痕迹应不影响主体识别，不形成统一装饰边框、贴纸阴影或 3D 浮雕。
9. **处理文字**：没有用户指定文字时，默认不加字；若需要主题名，只加入一行极少量、清晰可读的英文小字。文字应是安静的出版物标记，不是标题广告，不得生成伪文字、乱码、日期、地址或无意义编号。
10. **生成并验收**：生成后以缩略图和正常尺寸检查上下比例、主题识别、文字准确性、四色限制和印刷质感。若失败，只做一次针对性修正，不要同时改变全部方向。

## 参考图到下半部分的提炼规则

先用一句内部判断概括主题，例如“人物在狭窄通道中回望”或“孤树被开阔水面包围”。然后从以下项目中各选必要内容：

- **核心主体**：一个主体，或两个不可分离的主体。
- **识别轮廓**：姿态、外轮廓、动作方向、剪影或物体结构。
- **空间关系**：上下、远近、遮挡、面对、包围、穿过、聚散或斜向路径。
- **叙事关系**：谁在看谁、谁在靠近谁、什么正在发生、什么被留下。
- **关键记忆点**：最多四个，优先选择形状或关系，不选择无关的小装饰。
- **删减清单**：复杂背景、重复纹理、写实阴影、细碎人脸、无助于识别的物件。

下半部分必须同时满足：

- 单独看也像完整的独立出版物封面；
- 与上半部分共享至少一个轮廓、姿态、轴线、色彩关系或叙事关系；
- 看不到参考图时仍然有明确的主体层级；
- 看过上下两部分后能一眼理解它们属于同一主题；
- 再创作感来自删减、重组和印刷语言，而不是来自随机抽象或装饰。

## 构图与印刷约束

- 输出比例固定为 3:4 竖版；上下区域必须精确 1:1。
- 中央分割线应干净、明确、水平；除非用户明确要求，不使用斜切分割、波浪分割或不均等拼接。
- 上半部分承担“事实与来源”，下半部分承担“记忆与再创作”；两区不能互相抢夺主任务。
- 下半部分的有效主体建议占该区域约 15–40%，其余以米白纸和克制的材料痕迹为主。
- 允许主体靠左、靠右或略偏中心，但必须有稳定的视觉重心和足够呼吸空间。
- 不使用照片与插画之间的渐变融合；上下关系靠分割、色彩呼应、轮廓回声或版面节奏建立。
- 不使用厚重阴影、悬浮纸片、卷曲纸角、光泽、景深、透视 3D、塑料感或数字滤镜。
- 成品应像平面扫描或印刷品，不像样机展示、商品广告或商业旅游宣传。

## 输出规范

默认返回：

1. 生成的海报图像；
2. 一段简短中文创作说明，说明上半部分保留了什么、下半部分提炼了什么，以及专色如何帮助识别主题。

除非用户明确索要，否则不要展示完整生成提示词。不要把负面提示打印在图像里，也不要加入水印、署名、品牌标识或推广文案。

## 质量检查清单

生成前后确认：

- [ ] 画布确实为竖版 3:4。
- [ ] 上下两个区域各占 50%，分割线位于几何正中。
- [ ] 上半部分仍然是可识别、可信的参考图呈现。
- [ ] 下半部分不是描边、滤镜或写实复制，而是主题再创作。
- [ ] 下半部分主体小而集中，周围有大量有效留白。
- [ ] 参考主题的主体轮廓、姿态、空间或叙事关系至少保留两项。
- [ ] 下半部分最多使用 3–4 种专色，且颜色都能追溯到上方画面。
- [ ] 纸纤维、网点、错位、裁切和漏墨都克制，未变成装饰模板。
- [ ] 文字为空或极少量英文小字，清晰、拼写正确、没有伪文字。
- [ ] 没有水印、商业广告层级、3D、过度写实、纯线稿或廉价卡通感。
- [ ] 缩小查看时，上下两部分仍然属于同一主题，比例和层级没有失控。

如果只有一个问题需要修正，优先级为：比例与分割线 → 上半部分主体真实性 → 下半部分主题识别 → 色彩数量 → 留白与密度 → 印刷材料痕迹 → 文字。
