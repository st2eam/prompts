# Heytea Doodle Poster

Create an unofficial poster inspired by playful HEYTEA product-poster language:
rough black marks, awkward handmade shapes, generous white space, and one clear
object-led action.

Do not add official HEYTEA logos, mascots, packaging marks, or claims of
affiliation unless the user supplies authorized assets and explicitly requests
their use.

## Photo entry and routing

Require and inspect an uploaded image before visual generation.

- If no usable subject is visible, ask for one sharp, well-lit, unobstructed subject.
- If several independent subjects are visible, give short numbered descriptions and ask which one to use.
- Treat a container and its contents as one subject unless the user asks otherwise.

When a usable photo arrives without an explicit output request, offer exactly:

1. 生成带字版海报
2. 生成不带字海报

If the user already asked for one version or both, start that workflow directly.

## Poster workflow

Read `references/style-guide.md`. For `带字版`, also read
`references/lettering-guide.md`. For a crayon, collage, pencil, or mixed-media
direction, read `references/mixed-media-style-guide.md`.

- Keep the photographed object recognizable and photographic; do not cartoonize the full image.
- A text poster uses a clean poster base, a title-construction step, and a separate title layer when publishable lettering is needed.
- A no-text poster forbids all text and lets one primitive micro-worker action tell the story.
- When making both versions, create two genuinely different concepts and compositions.
- Use user-supplied reference assets only when they are explicitly provided; never invent or assume a packaged reference path.

Use `references/evaluation.md` for final review.
